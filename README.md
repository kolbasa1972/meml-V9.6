# MEML 9.6 — Axion Dark Matter from 6D QFT

## О модели

MEML 9.6 — спекулятивная игрушечная модель тёмной материи в рамках 6D квантовой теории поля. 
Тёмная материя описывается псевдоскалярным аксионом, возникающим из фазы комплексного 
объёмного скалярного поля на орбифолде M₄ × T²/Z₃.

### Ключевые результаты

| Параметр | Значение |
|---|---|
| Масштаб bulk-гравитации | M₆ ≈ 1.45 × 10¹⁷ ГэВ |
| Скалярный масштаб | M* ≈ 4.16 × 10¹³ ГэВ |
| Константа распада Печчеи–Квинн | f_a = 10¹² ГэВ |
| Масса аксиона | m_a ≈ 5.63 μэВ |
| Частота сигнала | ν_a ≈ 1.36 ГГц |
| Реликтовая плотность | Ω_a h² = 0.120017 (Planck 2018) |

---

## Запуск

```bash
python MEML9.6.py
```

Скрипт выполняет 10 проверок:

1. Топология орбифолда T²/Z₃
2. Масса аксиона
3. Частота сигнала
4. Реликтовая плотность (Planck 2018)
5. Разделение bulk/скалярного масштабов
6. Константа распада f_a
7. Невидимость для XENONnT/LZ (σ_SI = 0)
8. Инфляционные ограничения
9. Центральный заряд (контекст)
10. График Ω_a h²(θ_i) → `omega_vs_theta.png`

**Ожидаемый результат:** все 10 блоков — PASS.

## Статус модели

**Спекулятивная игрушечная модель** — не является законченной физической теорией.

- ✅ Численно самосогласованная
- ✅ Проверяемое предсказание (ADMX, ν_a ≈ 1.36 ГГц)
- ⚠️ Три свободных параметра: α_G, ε, θ_i
- ⚠️ Открытые проблемы: петлевые поправки, стабильность дефектов, вывод α_G из SU(5)
