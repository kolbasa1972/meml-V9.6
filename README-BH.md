# MEML 9.6 — Чёрные дыры: дополнение

Дополнение к работе [MEML 9.6](https://github.com/kolbasa1972/meml-V9.6) —
связь аксиона с физикой чёрных дыр.

**DOI основной работы:** [10.5281/zenodo.23289871](https://doi.org/10.5281/zenodo.23289871)

---

## О чём это

Аксион MEML 9.6 с массой m_a ≈ 5.63 мкэВ взаимодействует с
вращающимися чёрными дырами через **суперадиантность**
(Пенроуз, 1971; Зельдович, 1972).

### Ключевые результаты

| Параметр | Значение |
|---|---|
| Критическая масса ЧД | M_BH ~ 1.2 × 10⁻⁵ M_⊙ |
| Критическая масса аксионной звезды | M_crit ~ 1.6 × 10⁻⁵ M_⊙ |
| Условие суперадиантности | ω < m·Ω_H |
| Каналы проверки | LIGO O4/O5, EHT, PTA |
