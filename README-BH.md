# MEML 9.6 — Чёрные дыры: дополнение

Дополнение к основной работе [MEML 9.6](https://github.com/kolbasa1972/meml-V9.6) — связь аксиона с физикой чёрных дыр.

**DOI основной работы:** [10.5281/zenodo.23289871](https://doi.org/10.5281/zenodo.23289871)

---

## О чём это

Аксион MEML 9.6 с массой m_a ≈ 5.63 мкэВ взаимодействует с вращающимися чёрными дырами через **суперадиантность** (Пенроуз, 1971; Зельдович, 1972). Вращающаяся чёрная дыра усиливает волны, проходящие вблизи эргосферы, извлекая энергию из собственного вращения.

### Ключевые результаты

| Параметр | Значение |
|---|---|
| Критическая масса ЧД | M_BH ~ 1.2 × 10⁻⁵ M_⊙ |
| Критическая масса аксионной звезды | M_crit ~ 1.6 × 10⁻⁵ M_⊙ |
| Условие суперадиантности | ω < m·Ω_H |
| Каналы проверки | LIGO O4/O5, EHT, PTA (NANOGrav) |

**Замечательно:** критическая масса ЧД и критическая масса аксионной звезды совпадают — это фундаментальное свойство модели.

---

## Скрипт

- `MEML9.6-BH.py` — численный расчёт критических масс

### Запуск

```bash
python MEML9.6-BH.py
```

**Ожидаемый результат:**

- Критическая масса ЧД: M_BH ≈ 1.2 × 10⁻⁵ M_⊙
- Критическая масса аксионной звезды: M_crit ≈ 1.6 × 10⁻⁵ M_⊙
- Условие суперадиантности: ω_a < Ω_H — выполнено
- Отношение масс: M_BH / M_crit ≈ 0.77

# MEML 9.6 — Black Holes: Supplement

Supplement to [MEML 9.6](https://github.com/kolbasa1972/meml-V9.6) — connection of the axion to black hole physics.

**DOI of the main work:** [10.5281/zenodo.23289871](https://doi.org/10.5281/zenodo.23289871)

---

## About

The MEML 9.6 axion with mass m_a ≈ 5.63 μeV interacts with rotating black holes through **superradiance** (Penrose, 1971; Zeldovich, 1972). A rotating black hole amplifies waves passing near the ergosphere, extracting energy from its own rotation.

### Key Results

| Parameter | Value |
|---|---|
| Critical BH mass | M_BH ~ 1.2 × 10⁻⁵ M_⊙ |
| Critical axion star mass | M_crit ~ 1.6 × 10⁻⁵ M_⊙ |
| Superradiance condition | ω < m·Ω_H |
| Test channels | LIGO O4/O5, EHT, PTA (NANOGrav) |

**Remarkably:** the critical BH mass and the critical axion star mass coincide — a fundamental property of the model.

---

## Script

- `MEML9.6-BH.py` — numerical computation of critical masses

### Usage

```bash
python MEML9.6-BH.py
```

**Expected output:**

- Critical BH mass: M_BH ≈ 1.2 × 10⁻⁵ M_⊙
- Critical axion star mass: M_crit ≈ 1.6 × 10⁻⁵ M_⊙
- Superradiance condition: ω_a < Ω_H — satisfied
- Mass ratio: M_BH / M_crit ≈ 0.77
